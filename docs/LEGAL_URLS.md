# URLs públicas (Discord Developer Portal)

Com repositório **privado**, use as páginas servidas pelo bot no Railway (variável `SERVER_URL`):

| Campo | URL |
|-------|-----|
| **Terms of Service** | `{SERVER_URL}/terms-of-service` |
| **Privacy Policy** | `{SERVER_URL}/privacy-policy` |

Exemplo: `https://seu-app.up.railway.app/terms-of-service`

Arquivos HTML: `legal/terms-of-service.html`, `legal/privacy-policy.html`  
Cópias em Markdown (referência interna): `terms-of-service.md`, `privacy-policy.md`
